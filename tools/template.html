Conexión con el ModPack

La selección se guarda como selection.json en el repositorio . Los agentes del repo del ModPack leen ese archivo para instalar las skins en la Switch. Necesitas un token de GitHub (fine-grained) con permiso Contents: Read and write solo sobre ese repositorio. Se guarda únicamente en este dispositivo.

Sin token también puedes usar «Copiar JSON» en Mi selección y pegarlo donde quieras.
